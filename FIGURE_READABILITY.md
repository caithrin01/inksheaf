# Larger figures for reading

The held annual PDF has charts, maps and feed screenshots whose labels are too small.
The old repair tools could only shrink a figure or move it. The next publisher candidate
adds two measured enlargements: column width, or a quarter-turn landscape figure within
the existing 6×9 portrait leaf. Text, captions, image pixels and proportions stay intact.

The bitmap dimensions, physical text block and existing 150ppi floor bound each option.
Captions retain space below. The model receives only modes measured for the flagged figure;
it cannot invent a width, crop labels or clear illegibility as intentional space. An adopted
reading size persists through the fit loop and cannot be silently shrunk to fill an ending.
The next PDF receives the complete normal geometry and model review.

Before the first vision pass, compiled paragraph/figure positions now drive one bounded
batch that puts interrupting floats back between their source paragraphs. It consumes the
same six-render allowance and checks source hashes before showing the new draft. Remaining
interruptions still hold the book. A final available render pass can be used rather than
accidentally requesting zero passes while trying to reserve another repair round.

Typst rotation must participate in layout, using `reflow: true` according to the
[official rotate reference](https://typst.app/docs/reference/layout/rotate/). Compiled
measurements record the actual rotated bounds and the intended orientation for review.

Validation and actual annual acceptance remain separate. Test bitmap preservation, page
bounds, caption adjacency, larger printed size, model operation restrictions and persistence.
Then inspect the previously flagged owner figures locally before resuming any paid annual
review with its existing ledger. This follow-up is separate from the authorized PR #7 release.
